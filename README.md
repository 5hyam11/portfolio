# Shyam Narayan Sundararajan — Portfolio

Personal portfolio website for Shyam Narayan Sundararajan, Robotics Engineering student at UC Santa Cruz (GPA 3.93).

🔗 **Live site:** [5hyam11.github.io/portfolio](https://5hyam11.github.io/portfolio)

---

## About

A cyberpunk-themed interactive portfolio featuring a drone intro animation, dual robot arms that track your cursor, and a scroll-driven navigation system.

## Features

- Drone intro sequence with physics-driven flight and pacing
- Banner held by drone displays name + cycling role typewriter
- Scroll-driven transition — drone flies name to nav bar on scroll
- Dual IK robot arms with cursor tracking
- Sections: About, Projects, Education, Skills, Contact

## Stack

Pure HTML/CSS/JS — no frameworks, no dependencies, no build step. Single file.

## Projects Featured

- **ShopShadow** — Autonomous smart cart with YOLOv8, ONNX edge inference
- **ACT-Tac-Toe** — Autonomous manipulation via VLA models, trained on A100/H100
- **Jarvis** — Production RAG system for document-grounded inference
- **Quantum Robotic Learning** — Robot path-planning as QUBO optimization

## Running Locally

Just open `index.html` in any browser. No server required.

```bash
git clone https://github.com/5hyam11/portfolio.git
cd portfolio
open index.html
```

## Deployment

Hosted via GitHub Pages from the `main` branch.
